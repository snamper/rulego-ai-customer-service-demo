Get started

本地预览与真实后端接入

静态页面可以由 GitHub Pages 或任意 Web 服务器托管；AI、历史、客户与实时状态始终来自配置的 RuleGo Server。

启动静态页面

使用 Python 3 标准库，不需要安装前端依赖。

python3 serve.py

# 自定义端口
python3 serve.py --port 8080

准备服务端

导入规则链后配置 OpenAI 兼容模型、HTTPS API、WSS、CORS 和最小权限访问凭证。

${global.llm_url}
${global.llm_api_key}
${global.llm_model}
